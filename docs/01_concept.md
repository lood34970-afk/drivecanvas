# Drive Canvas — 한 장 콘셉트

## 한 줄 제안

> 반복되는 이동을 특별한 추억으로 만들고 싶은 운전자에게, 실제 도로 제약과 주행시간을 반영한 그림 모양 경로를 생성하고 안전한 음성 안내와 완주 콘텐츠를 제공한다.

## 타깃과 문제

- 핵심 사용자: 주말 드라이브를 즐기는 20~40대 운전자, 커플·가족, 여행지에서 특별한 기록을 남기고 싶은 사람
- 발생 상황: 목적지보다 드라이브 과정 자체를 즐기고 싶거나 기념일·여행의 색다른 활동을 찾을 때
- 현재 대안: 직접 지도에서 경유지를 찍거나 러닝·자전거용 GPS 아트 경로를 자동차로 변형
- 현재 대안의 손실: 일방통행, 회전 제한, 좁은 길, 위험 구간 때문에 모양이 깨지고 경로 작성에 시간이 많이 든다.

## 차량이어야 하는 이유

- 차량 내 내비게이션의 경로 안내·재탐색·주행 상태와 직접 연결할 수 있다.
- 출발 전 계획, 주행 중 최소 정보, 도착 후 상세 결과를 차량 상태에 따라 분리할 수 있다.
- 스마트폰 거치와 조작 없이 음성 안내에 집중하고, 완주 후에만 그림과 공유 카드를 보여 줄 수 있다.

## 핵심 흐름

1. 정차 상태에서 지역, 그림, 목표 시간 또는 거리를 선택한다.
2. 앱이 도로 제약과 안전 조건을 반영한 2~3개 경로를 만든다.
3. 사용자가 그림 유사도·시간·관광 경유지를 비교해 하나를 고른다.
4. 주행 중에는 일반 내비게이션처럼 최소한의 진행률과 음성 안내만 제공한다.
5. 완주 후 실제 GPS 궤적을 애니메이션과 공유 카드로 만든다.

## 핵심 기술 루프

`그림 템플릿 → 도로망 투영 → 주행 가능한 경유지·순서 생성 → NaviHelper 경로 안내 → 실제 위치 기록 → 완성도 계산·콘텐츠 생성`

## MVP와 데모

- 포함: 하트 템플릿 1개, 사전 선정 지역 1곳, 30~45분 코스, 경유지 안내, 실제 궤적 기록, 완주 카드
- 제외: 자유 손그림, 전국 자동 생성, 실시간 공동 주행, 브랜드 마켓플레이스
- 60초 데모: 하트 선택 → 두 경로 비교 → 안내 시작 → 위치 이동 시뮬레이션 → 완성된 하트 공개

## 가장 큰 리스크

- 사용자 가치: 결과를 한 번 공유한 뒤 다시 사용할 이유가 약할 수 있다.
- 기술: 도로망이 원하는 그림을 만들기에 부족하거나 경유지 제한으로 형상이 무너질 수 있다.
- 안전·정책: 운전 중 그림 확인과 조작이 주의분산을 일으킬 수 있다.
- 사업성: 불필요한 주행과 탄소 배출을 조장한다는 인상을 줄 수 있다.
